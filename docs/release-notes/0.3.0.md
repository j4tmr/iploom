# IPloom Studio 0.3.0

The first public release of IPloom Studio.

## Highlights

- Bilingual Chinese/English IP workspace.
- World → novel → chapter manuscript hierarchy.
- Reusable cross-universe cast and relationship graph.
- Local-first JSON persistence with atomic saves and backup recovery.
- ArcReel-style handoff packages with world, episode, storyboard and manifest files.
- Local stdio MCP server with eight tools and an Electron-bundled runtime.
- Universal macOS DMG/ZIP and Windows x64 NSIS builds.
- CI coverage for type checking, domain tests, real MCP transport, packaging and packaged-app startup.

## Downloads

- macOS universal: DMG and ZIP.
- Windows x64: NSIS installer.
- `SHA256SUMS.txt`: verify all assets.

## Important

This release is **not code-signed or notarized**. Gatekeeper and SmartScreen may warn. Verify the SHA-256 checksum and only continue if you trust the source.

Automatically derived scenes and shots are director drafts. Review all continuity, dialogue timing, generation calls and costs before production.

ArcReel is referenced as a compatible handoff target, not as an official integration.
