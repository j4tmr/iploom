# IPloom Studio 0.6.0

A focused minor release that lets local MCP clients write the story timeline. Workspaces do not change: schema stays at v7 and no migration runs on upgrade.

## Highlights

- **Timeline writes over MCP** — the new `create_timeline_event` tool adds an event anchored to a chapter or to an explicit in-world `story_time`, with subject kind and id, event kind, a bilingual title, before/after state, canon status, related characters, locations and objects, evidence and an optional production prompt. New events default to `proposed`.
- **Revision in place** — `update_timeline_event` edits an existing event. Omitted fields keep their current value, `chapter_id: null` or `scene_id: null` detaches the event from that anchor, and a title patch merges per language instead of replacing both.
- **The same validation as the app** — every write re-runs the timeline schema and reference checks before saving: the world must exist, the novel must belong to it, chapters and scenes must match, the subject must resolve for its kind, related ids must resolve, a scene requires its chapter, and an event needs a chapter or a non-empty story time. Unknown ids return a structured `not_found`; invalid arguments return `invalid_arguments` with field issues.
- **17 tools** — the local MCP server now registers 17 tools: twelve read-only, four writes (`create_standard`, `update_standard`, `create_timeline_event`, `update_timeline_event`) and one ArcReel export. README, the architecture guide and `docs/mcp.md` list the new tools and updated counts.

## Compatibility

- Workspace schema remains **v7**; existing workspaces open without migration.
- Both tools are additive, so existing client configurations keep working unchanged.
- Node.js 24 and Bun 1.4.2 remain the development prerequisites.

## Downloads

- macOS universal: DMG and ZIP.
- Windows x64: NSIS installer.
- `SHA256SUMS.txt`: verify all assets.

## Important

This release is **not code-signed or notarized**. Gatekeeper and SmartScreen may warn. Verify the SHA-256 checksum and only continue if you trust the source.

ArcReel is referenced as a compatible handoff target, not as an official integration.
