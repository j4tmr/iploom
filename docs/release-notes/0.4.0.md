# IPloom Studio 0.4.0

The first feature release since 0.3.0. It brings the manuscript import and AI production desk that were still source-only into the installers, adds a unified story timeline and project-wide foundation standards, expands the local MCP server, and hardens local persistence. Existing workspaces migrate automatically to schema v7 on first open.

## Highlights

- **Novel import** — import TXT/Markdown or paste text (up to 8 MB, 2 million characters, 1,000 chapters), preview the detected chapters, and optionally extract world, cast, relationships and scenes through a configured model API. Long imports split into bounded segments, completed segments survive a failure, and retry resumes at the first unfinished segment.
- **AI production desk** — nine editable prompt templates with dependent tasks, streamed output, cancel/retry, author review and result replacement. Approved outputs stay bounded, every run records its model and prompt hash, and replacing a result marks dependent tasks as superseded until they are re-reviewed.
- **Model API settings** — configure a Chat Completions-compatible endpoint, model and key in the desktop app. HTTPS is required except for loopback HTTP; the key lives only in main-process memory for the current session and never reaches the renderer or an export.
- **Story timeline** — one timeline for characters, scenes, locations and props, derived from chapter cast and location and scoped per chapter.
- **Foundation standards** — project-wide language, format, naming, numeric, entity-prompt and continuity rules with pinned versions, injected into every prompt and workflow brief.
- **Expanded local MCP** — fourteen tools, eleven read-only. Novel, chapter, standard, search and relationship-graph reads are paged and bounded, and reads are scoped before ranking.
- **Persistence integrity** — a stale-save guard, quarantine of an unreadable primary file, `.bak` recovery adopted as the new primary, recovery snapshots before destructive changes, atomic writes, and a save-before-close handshake scoped to each window.
- **Manuscript splitting** — chapter detection now handles bracket titles, volume subheadings, inline fences, titled Roman numerals and deeper classifier-recognized headings, while keeping the source text verbatim.
- **Search** — folded matching for multi-word and multi-script queries, including the highlighted result staying in view across queries.
- **Application update** — **Settings → Application update** checks GitHub Releases on demand and opens the platform download in the system browser; IPloom still never downloads or installs a release artifact itself.
- **Accessibility and localization** — dialog focus management, palette focus restoration and a Tab trap, and localized copy for the remaining untranslated controls.
- **CI and release hardening** — cross-platform desktop smoke on macOS and Windows, Intel-slice checks through Rosetta, pinned action SHAs, artifact-name assertions, checksums and build-provenance attestations.

## Workspace schema

Workspaces are migrated automatically to **schema v7**. The v5 → v6 repair strips composed model prompts that older builds had written back into task briefs and deliverables, so a cancelled run no longer loses the author's brief. The v6 → v7 migration pins an explicit prompt template on every workflow task, so a later title edit cannot silently change its instructions. The v4 → v5 export-history repair still runs first for older data.

Keep an independent backup before downgrading. Older 0.3.0 builds reject the v7 workspace and the wider workflow text limits.

## Important

This release is **not code-signed or notarized**. Gatekeeper and SmartScreen may warn. Verify the SHA-256 checksum and only continue if you trust the source.

Automatically derived scenes and shots are director drafts. Review all continuity, dialogue timing, generation calls and costs before production.

ArcReel is referenced as a compatible handoff target, not as an official integration.
