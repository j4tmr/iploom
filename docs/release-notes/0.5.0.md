# IPloom Studio 0.5.0

A focused minor release that opens the story timeline to local MCP clients. Workspaces do not change: schema stays at v7 and no migration runs on upgrade.

## Highlights

- **Timeline over MCP** — the new read-only `list_timeline_events` tool lists story timeline events with the same chapter → in-world time → order → creation-time sorting the desktop timeline uses. Filter by world, novel, chapter, subject kind and id, and canon status.
- **Bounded responses** — the default view clips long state, evidence and production-prompt fields and names them in `truncated_fields`; `include_details` returns the full record. Results use the usual paged envelope and response budget, so large timelines stay readable page by page.
- **Structured errors** — unknown worlds, novels and chapters return a parseable `not_found` error instead of dropping the stdio connection, so a client can correct the call and retry.
- **15 tools** — the local MCP server now registers 15 tools: twelve read-only, two foundation-standard writes and one ArcReel export. README, the architecture guide and `docs/mcp.md` list the new tool and updated counts.
- **Test isolation guard** — a static scan and runtime shim now reject `mock.module(...)` in the Studio suite, keeping tests from mutating shared module state across files.

## Compatibility

- Workspace schema remains **v7**; existing workspaces open without migration.
- The new MCP tool is additive, so existing client configurations keep working unchanged.
- Node.js 24 and Bun 1.4.2 remain the development prerequisites.

## Downloads

- macOS universal: DMG and ZIP.
- Windows x64: NSIS installer.

## Important

This release is **not code-signed or notarized**. Gatekeeper and SmartScreen may warn. Verify the SHA-256 checksum and only continue if you trust the source.

ArcReel is referenced as a compatible handoff target, not as an official integration.
